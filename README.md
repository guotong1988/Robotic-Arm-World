# Robotic Arm World

https://space.bilibili.com/447278957/lists

本项目基于 robosuite + Panda 实现 VLM 驱动的单臂操作。整体思路是：先在仿真环境中采集 2D 视觉识别与执行计划数据，用于微调 Qwen 多模态大模型；推理时，模型根据图像和指令生成操作计划，再结合 2D 像素与深度信息完成三维空间定位，最后通过逆运动学（IK）驱动机械臂执行操作。

采集、评测、步骤原语和深度定位的说明见 [QUICK_START.md](QUICK_START.md)。
